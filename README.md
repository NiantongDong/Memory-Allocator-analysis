## MOC setup

After we discussed the environment, we believe a VM in MOC is a better choice because we use totally different platform and the result may be affected by different platform. Also, it is hard to coordinate in local. So, the MOC is the best choice we have now.

The MOC VM has 4 VCPUS, 32 GB RAM, centos system.

